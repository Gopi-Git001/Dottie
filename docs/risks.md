## Open questions for Gopi (Product Owner)

1. **Q1 Distribution model: ANSWERED 2026-10-18.** Gopi: Dottie is for his personal, single-user use only (relayed by Dottie_Codex). App Server ChatGPT auth is permitted for this use (R1 mitigated, ADR-0002 Accepted). Revisit R1 and ADR-0002 before any sharing or commercial distribution.
2. **Q2 Test PC: ANSWERED 2026-10-18.** <pc-host>, Windows 11 Home build 26200.8875. This is below the 26200.9278 that MXC needs, so Windows Update must run before Week 1 (see R16).
3. **Q3 CODEX_HOME:** should Dottie keep its own Codex sign-in (recommended), or share your existing Codex CLI/app sign-in, where logging out of one logs out the other?
4. **Q4 Speech:** which STT/TTS provider (cloud vs on-device), and what monthly budget? Your ChatGPT plan does not cover these.
5. **Q5 Wake word:** do you accept Picovoice Porcupine licensing/cost for "Dottie", or require an open-source engine?
6. **Q6 API-key mode:** should an optional, separately billed API-key mode ever exist? (Default: no.)
7. **Q7 Repos:** may we create a new `dottie` monorepo, and should it be private? Should Dollie_Bot_Private and Groot_1.0 (résumé PII) be made private?
8. **Q8 Busy behaviour:** when you give a new command while a task is running, should Dottie queue it (default) or cancel-then-start?
9. **Q9 Architecture targets:** is Windows on ARM64 in scope for V1?
10. **Q10 Access:** please provide `MDC_First_agent` and `Dottie_Bot` so the audit's reuse claims can be checked (C5). *2026-10-19: MDC is partly resolved by a read-only mirror at `e10/mdc_mirror/voice-agent` (no LICENSE, see Q16). `Dottie_Bot` is still not on the box.*
11. **Q11 Bundling:** is shipping an embedded Python runtime plus Codex binaries (installer likely >200 MB) acceptable?
12. **Q12 Speech API key (new 2026-10-19):** if a cloud STT/TTS is chosen (Q4), whose key is it, and where may it live? Separately, may Dottie use the `OPENAI_API_KEY` already set on <pc-host> for gstack, or must speech get its own key? (Default: its own key, stored in Windows Credential Manager, never used for Codex; R16.) This is **not** Q6: Q6 is about Codex API-key mode.
13. **Q13 STT accuracy target (new):** the spec sets no speech-recognition accuracy target. What should Dottie get right? For example, "N of 100 everyday commands understood exactly in a quiet room with your mic". Until you answer, the WER/command-accuracy numbers are **PROVISIONAL and report-only** (DOT-072). We have not set a number.
14. **Q14 Hardware details (new):** for <pc-host>, which microphone(s) and speakers/headset will you use, how many monitors (and their scaling %), is it a desktop or a laptop (battery)? Is any second Windows machine or VM available for tests? (DOT-073)
15. **Q15 Lock screen (new):** when Windows is locked, should Dottie (a) close the mic entirely until unlock, or (b) keep listening for "Dottie" and only reply "unlock your PC first"? Either way it never acts on a locked desktop (spec §3 exclusion). Recommendation: (a).
16. **Q16 MDC licence (new):** `MDC_First_agent` has no LICENSE file. As its owner, do you permit copying its voice/echo/gate code into Dottie (with attribution)? Or should we only reuse ideas and write it fresh?
