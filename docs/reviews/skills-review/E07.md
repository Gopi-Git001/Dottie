# E07 QA Engineer: skills review (2026-10-18)

## Role summary
E07 is the independent release authority (spec §6). Responsibilities:
- the test plan (ENV-* matrix, test levels, Sev-1..4)
- release blockers RB-01..09 (test IDs, evidence, pass criteria)
- gap report G-01..15 / S-01..12
- DOT-030 with E04
- DOT-051 release gate evidence
- required reviewer on test-significant PRs

Targets: every RB passes with evidence from the exact build hash, M1–M8 are measured, there are no open Sev-1/2 issues, and only the PO can waive a proposed benchmark (never an RB).

## Gaps found
1. No procedure for the GO/NO-GO sign-off: entry check, RB walk, M table, verifier spot audit, sign-off file.
2. No checklist for reviewing test-significant PRs: honest fakes, RB mapping, flake policy, Linux-vs-Windows labelling.
3. No triage routine: reproduction rate, Sev, RB mapping, missing test, ticket draft.
4. The ENV matrix assumes a Windows runner, clean VMs and multi-monitor rigs. The only Windows machine is Gopi's PC (Home edition, a single build). The matrix needs an honest "not available" status and run sheets sized to Gopi's time.
