# E03 Agent Architect: skills review (2026-10-18)

## Role summary
E03 owns the coordinator (`packages/coordinator`, ADR-0010 state machine, DOT-013 ★): auth gate, dedupe/idempotency, side-effect ledger, honest stopStatus, queue policy, and approvals with E08 (DOT-014) and cancel propagation with E04 (DOT-041). Baseline 41/41 tests on fakes. Targets: no duplicate action, no clean-cancel claim with side effects, stop speaking never cancels a task, no auto-approval.

## Gaps found
1. The stop truth table and late-event cases (effect after ack, ack after timeout, pending approval) are not written down as a checklist.
2. No wiring recipe for real ports. `VerifierPort` returns a boolean, but the verifier has 4 outcomes. The App Server event → hook mapping and the actionId hash are not wired.
3. Retry/recovery rules are not tested as a set: `rate_limited` retry conflicts with CONTRACTS, re-auth must not resume, offline queue behaviour is undecided, and the 10 s dedupe window is not from the spec.
