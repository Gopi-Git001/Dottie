# E01 Lead Engineer: skills review (2026-10-18)

## Role summary
E01 is the sole integrator of shared interfaces and the owner of the critical path (spec §6–§7). It writes tickets with the 10 spec §7 fields, reviews the critical path daily, owns `docs/requirements-matrix.md` and `docs/dependencies.md` (DOT-009, spec §2/§16 first actions), co-owns the MDC reuse check (DOT-006 with E05), accepts ADRs, and reviews the agent-built modules before they merge (ARCHITECTURE C10).
Acceptance targets: every §3 V1 item maps to a ticket and a test; no "done" without automated checks, review and evidence; no private change to a shared interface.

## Gaps found
1. No recipe turns a BACKLOG row into a full spec §7 ticket or defines a mechanical done-check. Today the BACKLOG ACs are prose.
2. No process exists for the cross-package vocabulary drift. Auth state has 4 spellings, stopStatus 3, risk 3 (plus E04's), endReason 3, outcome 3+, envelope 3, and tool error codes 2. `packages/contracts` (DOT-007) can't be cut until this is decided.
3. DOT-009 has no method. `docs/requirements-matrix.md` and `docs/dependencies.md` don't exist yet. Licence red flags (MDC has no LICENSE; openWakeWord models are CC BY-NC-SA; Bot requirements are unpinned) are scattered across plans.
4. No daily critical-path routine. Only the Friday report exists.
