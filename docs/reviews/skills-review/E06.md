## Gaps found
1. No recipe exists for the 5-place IPC change (channels → ipc schemas → router → preload/renderer → tests/doc) or for its security checks.
2. Moving from stub to real adapter has no checklist. Several port mismatches are open:
   - `startLogin()` vs `beginLogin(mode)`
   - who opens the auth URL (CONTRACTS says the adapter; desktop does it)
   - the allowlist is broader than the `https://auth.openai.com/` prefix
   - no `auth:cancel-login` channel
   - VoiceService vs voice-plan names
3. No settings migration recipe: grants may only narrow, newer files stay read-only, and `%APPDATA%` vs `%LOCALAPPDATA%` locations differ.
4. No tray mapping change recipe. New inputs from E05 (cloud badge) and E09 (gave_up/envUnavailable) are coming.
